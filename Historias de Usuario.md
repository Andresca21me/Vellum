## 1. Introducción
Este documento define las historias de usuario del sistema **Vellum**, una aplicación de escritorio orientada a la creación, edición y gestión de notas interconectadas con capacidades avanzadas de formato de texto.

El objetivo de este documento es capturar las necesidades de los usuarios desde su perspectiva, estableciendo una base clara para el desarrollo del sistema y la posterior definición de requerimientos funcionales.

## 2. Actores
- **Estudiante:** Usuario que organiza conocimiento personal
- **Investigador:** Usuario que trabaja con información compleja y necesita trazabilidad
- **Escritor:** Usuario enfocado en la creación y edición de contenido
